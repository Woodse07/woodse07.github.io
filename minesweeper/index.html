How it’s built

The rules and the drawing are separate files: one holds the board and never touches the page, the other draws it and never decides anything about the game. A move comes back as the list of cells that changed, each carrying the distance it sits from wherever you clicked, and the stylesheet turns that number into an animation delay — which is why the board opens as a ripple rather than all at once, with no timer anywhere in the JavaScript.

Hand-written HTML, CSS and JavaScript, no framework and no dependencies, about twenty kilobytes all in.
